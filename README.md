# 🏡 Real Estate Sales Dashboard

## Project Overview
A Power BI dashboard built using Real Estate Sales Data to analyze property sales trends, city-wise performance, property types, and agent performance.

## Dataset
- Property_Sales (500 records)
- Agents (15 records)

## 📈 Key KPIs
- Total Sales Value
- Total Properties Sold
- Average Price per SqFt
- Highest Sale Value

## 📊 Dashboard Pages

### 1. Sales Overview
- KPI Cards
- Sales by City
- Property Type Distribution
- Sales Trend Analysis
- Filled Map
- Top 10 Highest Value Sales

### 2. Matrix Analysis
- Region vs Property Type Analysis
- Conditional Formatting

### 3. Agent Performance
- Agent-wise Sales Analysis
- Top 5 Agents by Sales
- Drillthrough Reporting

### 4. City Tooltip
- Average Price per SqFt Trend
